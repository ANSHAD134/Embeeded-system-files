## 🛠️ Tech Stack

- **Languages**: C, Embedded C
- **Hardware**: AVR (ATmega series), Arduino-compatible boards
- **Build System**: Makefile, avr-gcc
- **Tools/IDEs**: Arduino IDE, Microchip Studio / Atmel Studio, VS Code, GCC
- **Simulation**: Simulide, Tinkercad, or Serial Monitor tools

---

## ⚙️ Setup & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ANSHAD134/Embedded-system-files.git
   cd Embedded-system-files
   ```

2. Navigate to the folder you want (e.g. `AVR/`) and open the source file.

3. Compile using `avr-gcc` / `make`, or open the project in your preferred IDE (Arduino IDE, Microchip Studio, etc.).

4. Flash the compiled `.hex` file to your microcontroller using a programmer (USBasp, AVRISP, Arduino as ISP, etc.).
